# 🛍️ Product-GPT

**Product-GPT** is a smart, AI-powered agent that researches, analyzes, and compares products to give you the best recommendations. 

This repository is a **Lite Version / Proof of Concept (PoC)**. It is designed to run entirely on your local machine (`localhost`). The main goal of this project is to test the concept of automation using AI agents.

---

## 🚀 What Does It Do?

Instead of manually opening 10 different tabs to compare prices, features, and reviews for a product, Product-GPT does the heavy lifting for you. 
Using **Google's Gemini AI**, the agent can:
*   Understand your product requirements.
*   Research available options.
*   Analyze the pros and cons.
*   Provide a smart, automated recommendation.

---

## ⚠️ Project Status: Lite Version

Please note:

*   It is designed to run **locally** on your computer.
